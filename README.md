# Scure

**Scure** is a mobile-first URL security scanner that lets anyone check a link before they open it. Paste a URL, scan a QR code, or point the camera at text containing a link — Scure runs it through multiple threat-intelligence engines and an AI risk analysis, then returns a plain-English verdict: **clean**, **suspicious**, or **malicious**.

Built as a full-stack product (React Native mobile app + Node.js API), with a freemium subscription model, scan history, and admin-managed blocklists.

🔗 **[scure.up.railway.app](https://scure.up.railway.app)** — visit for the app itself and a fuller description.

## Why

Phishing and malicious links spread fastest through channels people already trust — texts, QR codes on posters, screenshots. Scure gives non-technical users a one-tap way to verify a URL is safe *before* they tap it, without needing to understand threat intel jargon.

## How it works

Every scan runs the target URL through several engines in parallel and combines the results into a single risk score:

| Engine | What it checks |
|---|---|
| **Google Safe Browsing** | Known phishing / malware listings |
| **VirusTotal** | Aggregated verdicts from 70+ AV/security vendors |
| **URLScan.io** | Live sandboxed page scan, screenshot, network behavior |
| **Gemini AI script analysis** | Reads the page's scripts and flags suspicious behavior (obfuscation, redirects, credential harvesting patterns) |
| **Embedded link crawl** | Extracts links found on the page and checks each one too |
| **Community/regulatory blocklist** | Supabase-backed blocklist seeded from URLhaus + auto-synced from prior malicious scans; includes government-banned URLs (e.g. CSA Singapore) that can't be bypassed |

The scores are combined into an overall verdict, a 0–100 risk score, and a human-readable suggestion generated by an LLM (Gemini/Groq).

**Premium** users additionally get:
- **Ad Intensive Detection** — a headless-browser (Playwright) pass that intercepts ad-network requests, detects dynamically injected scripts, watches for popups, and captures screenshots through the page lifecycle.
- Fast-path blocklist short-circuiting with the option to continue to a full scan anyway.

There's also a standalone **Fact Check** mode that extracts a page's text content and asks an LLM to flag likely misinformation.

## How you interact with it

- **Paste a URL** and scan it directly
- **Scan a QR code** with the camera (on-device barcode detection)
- **Point the camera at text** (OCR via ML Kit / Tesseract) to pull a URL out of an image and scan it
- Browse **scan history**, see **publicly shared scan results**, manage account/subscription, and submit support tickets — all from the mobile app

## Tech stack

**Mobile app** (`mobile-app/`)
- React Native + [Expo](https://expo.dev), file-based routing via `expo-router`
- On-device camera/QR scanning (`react-native-vision-camera`, `@react-native-ml-kit/barcode-scanning`)
- On-device OCR (`@react-native-ml-kit/text-recognition`)
- Local push notifications for scan completion
- JWT auth persisted via secure storage

**Backend** (`backend/`)
- Node.js + Express (ESM)
- PostgreSQL via [Supabase](https://supabase.com)
- [Playwright](https://playwright.dev) for headless page inspection, ad detection, and screenshotting
- Google Gemini + Groq for AI-driven risk suggestions and misinformation analysis
- JWT auth, rate limiting, bcrypt password hashing
- Deployed on [Railway](https://railway.app) with CI auto-deploy from `develop`

## Architecture at a glance

```
mobile-app (Expo / React Native)
   │  REST + JWT
   ▼
backend (Express API)
   ├─ scan.service.js      → orchestrates the multi-engine scan
   ├─ urlScan / virusTotal / safeBrowsing utils → external threat intel
   ├─ geminiAnalysis.js    → AI script analysis, risk suggestion, fact-check
   ├─ adDetection.js       → Playwright-based ad/popup inspection (premium)
   ├─ blocklist.service.js → Supabase blocklist, URLhaus sync
   └─ scanHistory / subscription / userAccount / tickets services
   │
   ▼
Supabase (PostgreSQL) — users, subscriptions, scan history, blocklist, tickets
```
